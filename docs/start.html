The fastest path to superpowers

Start building with Brackets.

Brackets is a no-build, HTML-first, Datastar-powered framework. You can start from a desktop folder, keep your app in normal files, and move that same app to production when you are ready.

First hour

  1. Download Brackets and unzip it anywhere.
  2. Open the folder and look at framework/, app/, config.yaml, and index.html.
  3. Run config show and info.
  4. Run health and test app.
  5. Read the guide and start from one page, one template, and one behavior file.

The modern model

Brackets is file-first in shape, but fully dynamic in behavior. The split is simple on purpose.

.view and .html

Define the UI, page shape, layouts, and components.

.logic

Defines behavior, orchestration, actions, and routing logic.

.data

Defines the model layer, validation, transforms, queries, and local persistence rules.

.api

Adds optional remote sync, shared authority, and external services.

Pick the workflow that fits

Goal Best path
Simple website Start with a small .view, one .html, and light .logic.
Fast SPA Use routing, layout preservation, prefetch, and Datastar-powered updates.
Local-first app Move model code into .data and persist through .json, .yaml, or .db.
Connected app Keep the same frontend contract and plug in .api for any backend.

Checks and type safety

Brackets does not rely on a build step for safety. Use the built-in checks often and keep files small, clear, and honest about their job.
