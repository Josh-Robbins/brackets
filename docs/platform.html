Platform

Brackets keeps one app model across desktop-folder development, static servers, Docker, and paired backends. The shape stays simple even when the deployment grows up.

Deployment profiles

  • Desktop-folder or local-host: local files, local persistence, same-origin host when needed.
  • Static server: same UI model, same routes, optional local-first behavior, optional remote authority.
  • Paired backend: same frontend contract, plus .api for shared authority.

Docker

Docker is a packaging and hosting path, not a new framework model. Mount the app, keep persistent storage explicit, and keep Brackets same-origin where possible. 

services:
  brackets:
    image: your-brackets-host
    volumes:
      - ./app:/srv/brackets/app
      - ./storage:/srv/brackets/storage

Backends

Brackets stays backend agnostic. C#, Tauri, .NET, Go, Rust, Python, PHP, Ruby, Java, Node, or a flat-file backend can all fit behind .api without changing the frontend language.
